# Painel WhatsApp

Aplicativo de atendimento que mostra 5 números de WhatsApp na mesma tela.

**Download:** veja a [última versão](../../releases/latest).

- Windows 10/11: `Painel-WhatsApp-Windows-Instalador.exe`
- Mac (macOS 12 ou mais recente): `Painel-WhatsApp-Mac.dmg`
- Guia de instalação e uso: `Guia-Painel-WhatsApp.pdf`
